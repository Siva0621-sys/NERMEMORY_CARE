## 📱 How to Run from GitHub

Clone the repository and run it locally with Flutter:

```bash
# 1. Clone the repository
git clone https://github.com/Siva0621-sys/SOLVEAI.git

# 2. Navigate to project folder
cd SOLVEAI

# 3. Fetch dependencies
flutter pub get

# 4. Run the app in Chrome
flutter run -d chrome

# Or run as Windows desktop app
flutter run -d windows
```

To run all automated test suites:
```bash
flutter test
```

To run code static analysis:
```bash
dart analyze lib test
```

## 💡 About the Solution

Elderly people experiencing dementia in the North Eastern Region of India face challenges in accessing specialized neurological care and cognitive therapy. 

**NER MemoryCare** is a calming, supportive digital companion that provides:
1. **Elderly User Mode ("Meena")**:
   - Ultra-large typography and touch targets (56dp+).
   - High contrast, uncluttered screen layout.
   - 4 accessible daily tiles: *Memory Games*, *Daily Reminders*, *My Stars*, and *Help & Support*.
   - Prominent, reassuring *"Play a Game"* action.
2. **Caregiver Dashboard**:
   - Daily care overview and patient status.
   - Statistics: Games completed, total activity time, accuracy %, and current streak.
   - Daily activity timeline with morning, afternoon, and evening routines.
   - Full reminder scheduling (add, edit, toggle, delete).
3. **3 Interactive Playable Cognitive Games**:
   - **Memory Match**: 8-card grid featuring familiar North Eastern cultural symbols (Assam Tea Leaf, Great Hornbill, Blue Vanda Orchid, Mizoram Bamboo).
   - **Remember the Picture**: Timed visual recall test with non-punitive gentle mechanics.
   - **Everyday Objects**: Household object recognition fostering daily cognitive orientation (Tea Cup, Wall Clock, Chair, Book).
4. **Accessibility Suite**:
   - Text scaling: Normal (100%), Large (120%), Extra Large (135%).
   - High Contrast Mode toggle for low vision.
   - Reduce motion/animations toggle.
   - Voice assistant simulation for vernacular AI conversations.
   - One-tap emergency contact calling (Caregiver, Doctor, National Senior Citizen Helpline 14567).
